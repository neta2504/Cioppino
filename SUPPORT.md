# Support

Cioppino is community-maintained early-stage software.

## Getting help

1. Review the README troubleshooting and privacy sections.
2. Search existing GitHub issues.
3. Open a bug report using the repository issue form.

Include the Cioppino version, operating system, Node.js version, expected behavior,
actual behavior, and sanitized reproduction steps.

Do not upload real transcripts, databases, credentials, environment files, or logs
containing usernames, project names, tokens, URLs, or personal paths.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md).

## Supported scope

The v0.1.x release line targets Windows and macOS with Node.js 24. Linux, WSL,
containers, remote machines, cloud-hosted agents, native installers, and
code-signed artifacts are outside the supported scope.

Agent log and configuration formats change without notice. A supported agent may
temporarily lose partial coverage until its parser is updated.
